# Изоляция синтетической аналитики — 19 октября 2026

В полном Python3.11/network-none прогоне463 тестов один тест повторного расчёта
аналитики получил пустые профили (462PASS/1FAIL). Изолированный повтор прошёл.
При чтении кода обнаружена гонка стенда: seed удаляет стартовые telemetry gaps,
но фоновый collector с пустым списком датчиков ещё может дописать disabled-gap.
Такой gap законно исключает дни из аналитики. Это объяснение по коду, не трасса
конкретной межпоточной последовательности упавшего прогона.

В configure тестов аналитики теперь явно останавливается collector **до seed**,
как уже сделано в tests/test_suggestions.py. Поведение production не изменено,
сетевые ограничения и синтетическая SQLite сохранены. Повторные проверки записаны
в отчёте текущей TASK-26; исходное падение не выдаётся за успешный прогон.
