## 4. Нюансы, которые учитывать в следующих задачах

1. **TASK-01 — исправлено имя ключа.** Settings.api_key использует alias `SHADE_API_KEY`, без значения по умолчанию. Окружение перекрывает `.env`; `API_KEY` больше не используется. `python -m app.setup` создаёт ключ, но не запускает Core и не меняет корректный существующий ключ. Минимум 32 ASCII-символа без пробелов.
2. **TASK-01 — исправлена установка.** [requirements.txt](../core/requirements.txt) содержит зависимости приложения, [requirements-dev.txt](../core/requirements-dev.txt) — дополнение для тестов/ruff. Прямые версии закреплены, транзитивные полностью не зафиксированы. LLM-зависимости отдельные. Docker включает пустой шаблон и приложение, ключ передаётся снаружи.
3. **TASK-02 — тесты изолированы.** [conftest.py](../core/tests/conftest.py) в pytest_configure меняет рабочую директорию и настройки до импорта Settings/engine; fixtures дают отдельную SQLite-БД на API-тест, MockTransport для HA и запрет DNS/TCP. Параметры из рабочего `.env` и окружения не используются. Движок освобождается через portal TestClient до закрытия event loop. Несколько клиентов одновременно в одном процессе не предусмотрены, поскольку исходный Core использует общие настройки/engine. Дальнейшие API-тесты писать через fixtures client/auth_headers/ha_mock и дополнять mock.
4. **TASK-03/09 — сборка, транспорт и подключение.** Импорт Composable исправлен; APK и экран проверены на эмуляторе. Manifest подключает [Network Security Config](../android/app/src/main/res/xml/network_security_config.xml): HTTP только для точных адресов 192.168.1.100, 10.0.2.2, 127.0.0.1, localhost, shade.local; HTTPS со штатной проверкой сертификатов. Для другого IP добавить конкретный адрес и пересобрать APK либо использовать доверенный HTTPS. [ShadeApi.kt](../android/app/src/main/java/com/shadeai/app/core/network/ShadeApi.kt) теперь добавляет Bearer к защищённым запросам; настройка ключа реализована в TASK-09, health без Bearer. Разрешение уведомлений включается вручную через системный переход с экрана TASK-10. Локальные инструменты JDK 17/SDK настроены, SDK в android/.gradle/, команда в [инструкции](../android/README.md); SDK/Gradle-кэш/APK не входят в git. При конфликте старого ANDROID_SDK_ROOT использовать env -u ANDROID_SDK_ROOT.
5. **TASK-05 — правила приёма.** API/хранение описаны в [контракте](api-spec.md#41-уведомления-notifications--реализовано-в-task-05). POST возвращает stored/duplicate/skipped без вызова заглушки/шины сырого текста. event_id — стабильный UUID отправителя; без него SHA-256 нормализованных app/title/text/time/priority, одинаковые события в один момент неразличимы. Повтор UUID с другим содержимым даёт 409. Статус skipped с id=null — окончательный пропуск; DTO Android это допускает. Приём фильтрует до записи, но Android-фильтрация перед Room реализована в TASK-10; дополнительные форматы/обновления остаются TASK-11. Серверные allowlist/слова кодов консервативны, а не универсальный NLP-классификатор. Не включать банки/мессенджеры ради теста доставки.
6. **TASK-12 — надёжность доставки.** HTTP выполняет только WorkManager через общий capture, до 100 строк/45 с, затем следующая порция/задержка. Полный офлайн не начинает HTTP; появление сети заменяет ожидающую работу, но не сбрасывает серверный gate. В Room единая delivery_control: failures/nextAttemptAt/blocked/revision. Ошибки сети/408/425/429/5xx дают 30 с→6 ч, 401/403/config/TLS/receipt останавливают до сохранения настроек, 400/409/413/422 завершают только строку как REJECTED. Result/gate атомарны; ошибка БД должна доходить до worker, иначе возможен быстрый цикл. Несекретная revision меняется на save/clear, настройки сериализованы с отправкой. WorkManager Data без ключей/URL/текста; recovery раз в минимум 15 мин страхует потерю пробуждения, не обещает срок. Источник/доступ проверять перед каждым HTTP. Force-stop требует запуска приложения. Подробности/воспроизведение/аппаратные ограничения — [инструкция](../android/README.md#надёжная-доставка-и-повторы-task-12), [отчёт](reports/task-12.md).

8. **Развёртывание веба.** Vite проксирует /api на localhost:8000 только в dev-режиме. FastAPI не раздаёт web/dist; production-сервер и прокси нужно реализовать в TASK-08.
9. **БД — схема только через миграции.** Новые изменения оформлять новой ревизией и моделью; старые ревизии не импортируют текущие модели. Размер — main+WAL, LLM/worker/analytics отсутствуют. HA_TIMEOUT_SECONDS=5 ограничивает каждый обмен, ping также 2 секунды; общий client без redirect/proxy env, HTTPS со штатной проверкой. Ограничения переполнения/потери metadata и воспроизведение — [Android README](../android/README.md#форматы-идентичность-и-локальный-буфер-task-11), [отчёт](reports/task-11.md).
